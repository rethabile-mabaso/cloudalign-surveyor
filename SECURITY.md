# Security Policy

## Supported Versions
Security updates are provided for the current active MVP version of Cloudalign Surveyor.

## Reporting a Vulnerability
If you discover a security vulnerability within Cloudalign Surveyor, please report it directly to the Cloudalign security team rather than opening a public issue.
- Email: rethabile.mabaso@cloudalign.co.ls and/ masheane.sekopo@cloudalign.co.ls and/ letjamela.mabea@cloudalign.co.ls
- All security reports will be reviewed promptly.
